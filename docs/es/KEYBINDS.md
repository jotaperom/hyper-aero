# Atajos

[← Volver al README](../../README.es.md) · [English](../en/KEYBINDS.md)

`SUPER` es la tecla de Windows. Presioná `SUPER + F1` cuando querás para ver esta lista en pantalla.

## Apps y lanzadores

| Teclas | Acción |
|---|---|
| `SUPER + R` | Teléfono NEXUS: apps |
| `SUPER + SHIFT + R` | Lanzador clásico (rofi) |
| `SUPER + Q` | Terminal (kitty) |
| `SUPER + B` | Navegador |
| `SUPER + E` | Administrador de archivos |
| `SUPER + X` | Teléfono NEXUS: control |
| `SUPER + I` | Teléfono NEXUS: hoy (reloj, clima, nota) |
| `SUPER + W` | Wi-Fi (teléfono) |
| `SUPER + SHIFT + W` | Wi-Fi (rofi) |
| `SUPER + A` | Bluetooth (teléfono) |

## Ventanas

| Teclas | Acción |
|---|---|
| `SUPER + C` | Cerrar ventana |
| `SUPER + V` | Flotante / mosaico |
| `SUPER + J` | Cambiar la dirección de división |
| `SUPER + SHIFT + P` | Pseudo-mosaico |
| `SUPER + flechas` | Mover el foco |
| `SUPER + arrastrar con clic izquierdo` | Mover ventana (arrastrala al borde para mandarla a otro escritorio) |
| `SUPER + arrastrar con clic derecho` | Cambiar tamaño |
| `SUPER + CTRL + SHIFT + ←/→` | Mover la ventana al escritorio siguiente / anterior |
| `ALT + TAB` | Cambiar de ventana (mantené ALT, tocá TAB) |
| `ALT + SHIFT + TAB` | Cambiar de ventana hacia atrás |

## Escritorios

| Teclas | Acción |
|---|---|
| `SUPER + 1 … 0` | Ir al escritorio |
| `SUPER + SHIFT + 1 … 0` | Mandar la ventana al escritorio |
| `SUPER + TAB` | Vista de escritorios |
| `SUPER + rueda` | Escritorio siguiente / anterior |
| `SUPER + S` | Mostrar el scratchpad |
| `SUPER + ALT + S` | Mandar la ventana al scratchpad |

## Apariencia

| Teclas | Acción |
|---|---|
| `SUPER + G` | Carrusel de temas |
| `SUPER + T` | Día / noche (manual) |
| `SUPER + ALT + T` | Día / noche automático |
| `SUPER + SHIFT + T` | Luz cálida sí / no |
| `SUPER + D` | Widgets de escritorio sí / no |
| `SUPER + ALT + D` | Editar el escritorio |
| `SUPER + H` | TELEMETRY HUD completo / delgado |
| `SUPER + SHIFT + B` | Ocultar / mostrar la barra |
| `SUPER + SHIFT + D` | Pausar / reanudar el fondo animado |
| `SUPER + F2` | Perfil de rendimiento |
| `SUPER + P` | Pantallas (duplicar, extender, acomodar) |

## Sistema

| Teclas | Acción |
|---|---|
| `SUPER + L` | Bloquear |
| `SUPER + N` | Centro de notificaciones |
| `SUPER + SHIFT + N` | No molestar |
| `SUPER + M` | Cerrar sesión |
| `SUPER + F1` | Lista de atajos |
| `SUPER + F12` | Editar tu `user.lua` |

## Capturas

| Teclas | Acción |
|---|---|
| `SUPER + SHIFT + S` | Captura de una región |
| `Impr` | Captura de toda la pantalla |
| `SUPER + Impr` | Captura de la ventana activa |
| `SUPER + ALT + R` | Grabar la pantalla (repetí para detener) |
| `SUPER + ALT + SHIFT + R` | Grabar una región |

## Teclas multimedia

Volumen, silencio, silencio del micrófono, brillo y reproducir / pausar / siguiente / anterior funcionan como siempre y muestran un indicador en pantalla.

## Terminal

| Teclas | Acción |
|---|---|
| `CTRL + SHIFT + A`, luego `M` | Más escarcha (transparencia) |
| `CTRL + SHIFT + A`, luego `L` | Menos escarcha |

Para cambiar o agregar atajos, ver [Personalizar](CUSTOMIZING.md#atajos).
