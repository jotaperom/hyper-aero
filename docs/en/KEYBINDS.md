# Keybinds

[← Back to README](../../README.md) · [Español](../es/KEYBINDS.md)

`SUPER` is the Windows key. Press `SUPER + F1` at any time to see this list on screen.

## Apps and launchers

| Keys | Action |
|---|---|
| `SUPER + R` | NEXUS phone — apps |
| `SUPER + SHIFT + R` | Classic launcher (rofi) |
| `SUPER + Q` | Terminal (kitty) |
| `SUPER + B` | Browser |
| `SUPER + E` | File manager |
| `SUPER + X` | NEXUS phone — controls |
| `SUPER + I` | NEXUS phone — today (clock, weather, note) |
| `SUPER + W` | Wi-Fi (phone) |
| `SUPER + SHIFT + W` | Wi-Fi (rofi) |
| `SUPER + A` | Bluetooth (phone) |
| `SUPER + O` | Control Panel |
| `SUPER + Z` / `SUPER + middle click` | Radial menu around the cursor (1–8 or click to pick, Esc to close) |

## Windows

| Keys | Action |
|---|---|
| `SUPER + C` | Close window |
| `SUPER + V` | Float / tile |
| `SUPER + F` | Fullscreen on / off |
| `SUPER + SHIFT + F` | Maximize (keeps the bar and gaps) |
| `SUPER + J` | Flip split direction |
| `SUPER + SHIFT + P` | Pseudo-tile |
| `SUPER + arrows` | Move focus |
| `SUPER + left drag` | Move window (hold it at the outer edge of the screen, or drop it on a desktop tile at the top, to send it to another desktop) |
| `SUPER + right drag` | Resize window |
| `SUPER + CTRL + SHIFT + ←/→` | Move window to the next / previous desktop |
| `ALT + TAB` | Switch windows (hold ALT, tap TAB) |
| `ALT + SHIFT + TAB` | Switch windows backwards |
| `SUPER + ALT + TAB` / `SUPER + SHIFT + TAB` | Flip 3D (Tab or scroll to flip, Enter or release SUPER to open) |
| `SUPER + ,` (hold) | Aero Peek: look at the desktop through your windows |
| `SUPER + drag` and shake | Aero Shake: minimize the other windows (shake again to restore) |

## Workspaces

| Keys | Action |
|---|---|
| `SUPER + 1 … 0` | Go to workspace |
| `SUPER + SHIFT + 1 … 0` | Send window to workspace |
| `SUPER + TAB` | Workspace overview |
| `SUPER + scroll` | Next / previous workspace |
| `SUPER + S` | Show scratchpad |
| `SUPER + ALT + S` | Send window to scratchpad |

| `SUPER + ALT + T` | Day / night automatic |

## System

| Keys | Action |
|---|---|
| `SUPER + L` | Lock |
| `SUPER + N` | Notification center |
| `SUPER + SHIFT + N` | Do not disturb |
| `SUPER + M` | Log out |

## Tools

| Keys | Action |
|---|---|
| `SUPER + SHIFT + V` | Clipboard history (phone) |
| `SUPER + .` | Emoji picker (phone) |
| `SUPER + SHIFT + C` | Color picker (copies the hex code) |

## Capture

| Keys | Action |
|---|---|
| `SUPER + SHIFT + S` | Screenshot of a region |
| `Print` | Screenshot of the whole screen |
| `SUPER + Print` | Screenshot of the active window |
| `SUPER + ALT + R` | Record the screen (press again to stop) |
| `SUPER + ALT + SHIFT + R` | Record a region |

## Media keys

Volume, mute, microphone mute, brightness and play / pause / next / previous work as usual and show an on-screen indicator.

## Terminal

| Keys | Action |
|---|---|
| `CTRL + SHIFT + A`, then `M` | More frost (transparency) |
| `CTRL + SHIFT + A`, then `L` | Less frost |

To change or add shortcuts, see [Customizing](CUSTOMIZING.md#keybinds).
